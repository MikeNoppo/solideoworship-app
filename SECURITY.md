# Security Policy

## Supported Versions

SolideoWorship is currently in beta (`0.1.x`). Security fixes are applied to the latest beta release on `main`.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately using [GitHub Security Advisories](https://github.com/MikeNoppo/solideoworship-app/security/advisories/new). Include:

- A description of the issue and potential impact
- Steps to reproduce or a minimal proof of concept
- Your OS and SolideoWorship version

We will acknowledge your report and work on a fix before public disclosure.
